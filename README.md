
# 👗 Lane Castro Store - Link Tree Customizado

Este projeto é uma página de links (Link Tree) personalizada e sofisticada para a **Lane Castro Store**. Desenvolvida com **Next.js**, a página apresenta uma estética *Glassmorphism* inspirada no iOS, focada em converter seguidores do Instagram em clientes através de um design limpo e botões de ação direta.

## ✨ Demonstração Visual

* **Design Sofisticado:** Paleta de cores nude com efeitos de vidro embaçado (Blur).
* **Responsividade:** Otimizado para visualização perfeita em dispositivos móveis.
* **Integrações:** Links diretos para WhatsApp, Instagram, Localização via Google Maps e Grupo VIP de novidades.

## 🚀 Tecnologias Utilizadas

* **Framework:** [Next.js](https://nextjs.org/)
* **Linguagem:** TypeScript
* **Estilização:** CSS Modules com técnicas de Glassmorphism
* **Ícones:** [Lucide-React](https://lucide.dev/)
* **Fontes:** Montserrat e Playfair Display (via Google Fonts)

## 🛠️ Como rodar o projeto localmente

Siga os passos abaixo para configurar o ambiente de desenvolvimento:

1. **Clone o repositório:**
```bash
git clone https://github.com/seu-usuario/lanestore.git

```


2. **Entre na pasta do projeto:**
```bash
cd lanestore

```


3. **Instale as dependências:**
```bash
npm install
# ou
yarn install

```


4. **Inicie o servidor de desenvolvimento:**
```bash
npm run dev
# ou
yarn dev

```


5. **Acesse no navegador:**
Abra [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) para ver o resultado.

## 📁 Estrutura de Pastas Principal

```text
/public         # Imagens das marcas (Farm, Fenzzo, Dimy, etc.) e Logo
/src
  /components   # Componente LinkTree.tsx # Componente Linktree.module.css
  /styles       # Globals styles (Estilos customizados)
  /pages        # Rotas da aplicação (Next.js Pages Router)

```
